GitHub Pages project page for:

**SpikeHash: Learning Binary Codes with Spiking Neural Networks for Cross-Modal Hashing Retrieval**

Paper PDF:

```text
https://arxiv.org/pdf/2606.00740
```

Target URL:

```text
https://shuqiao-111.github.io/
```

## Directory structure

```text
shuqiao-111.github.io/
├── index.html
├── .nojekyll
├── README.md
└── assets/
    ├── css/
    ├── js/
    ├── figures/
    │   ├── pdf/
    │   └── svg/
    └── images/
```

## Publish

Upload the contents of this folder directly to the root of the `shuqiao-111.github.io` repository.

Correct:

```text
shuqiao-111.github.io/index.html
shuqiao-111.github.io/assets/
```

Incorrect:

```text
shuqiao-111.github.io/shuqiao-111.github.io/index.html
```

Then set GitHub Pages to:

```text
Settings → Pages → Deploy from a branch → main / root
```


## Figure rendering

Figures are rendered in the webpage as high-resolution PNG images exported from the original PDF figures. The original PDF files are retained under `assets/figures/pdf/` and linked from figure captions.
